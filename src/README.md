# Source Code

All source code for the HotPi Reflow Oven Controller.

- **`server/`** - Backend server (HTTP, WebSocket, serial communication with T-962)
- **`frontend/`** - Web frontend (UI, WebSocket client, profile editor, charts)
- **`run/`** - Deployment and build scripts
- **`utils/`** - Shared utility functions used across the application
